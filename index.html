Wie können wir helfen?

Eine Frage zur App, ein Hinweis zu einer Aktion oder Interesse an einer Partnerschaft? Schreib uns.

Dorthin können wir dir antworten. Bitte keine Passwörter, Zahlungs- oder Teilnahmedaten senden.

Deine Angaben werden über das bestehende Hoststar-Hosting per E-Mail an den PrizeCue-Support weitergeleitet und für die Bearbeitung deiner Anfrage verwendet. Auf GitHub werden keine Formularnachrichten gespeichert. Zum Schutz vor Missbrauch speichert der Versanddienst kurzzeitig eine gehashte technische Kennung; Nachrichteninhalte werden dort nicht als Formulararchiv abgelegt.

PrizeCue vermittelt Informationen zu fremden Aktionen. Die Teilnahme erfolgt beim jeweiligen Veranstalter.
